============================================================
  dy-scraper2.2 —— 使用说明
  v2.2 | 免费版 + 会员版 | 远程授权验证
============================================================

【一、环境要求】
  - Windows 10/11 64位
  - Python 3.10+
  - 能正常访问抖音网站的网络

【二、首次安装】

  第1步：安装 Python 依赖
    打开终端（PowerShell），进入程序目录：

    cd D:\dy-scraper
    pip install -r requirements.txt

  第2步：安装 Playwright 浏览器（仅首次）

    python -m playwright install chromium

    这一步下载约 150MB，等待完成。

  第3步：启动程序

    python app.py

    看到以下输出表示启动成功：
    * Running on http://127.0.0.1:8080

  第4步：打开浏览器访问

    http://127.0.0.1:8080

【三、License 激活】

  免费版限制：
  - 仅支持采集单个视频的评论
  - 单次最多采集 2 条视频

  会员版特权：
  - 博主主页全量视频采集
  - 搜索关键词结果采集
  - 批量指定视频采集
  - 无采集数量限制

  激活步骤：
  1. 点击页面右上角「免费版」徽章
  2. 弹出激活窗口，复制显示的机器码
  3. 将机器码发给管理员获取 License Key
  4. 将 Key 粘贴到输入框，点击「激活」
  5. 激活成功后徽章变为「会员版」，全部功能解锁



  设备绑定说明：
    License Key 通过密码学签名与机器码绑定，一个 Key 只能用于一台
    电脑。换电脑后旧 Key 无法使用，需联系管理员用新机器的机器码
    重新生成 Key。

  离线使用：
    激活后会自动缓存 License，断网状态下仍可正常使用会员功能，
    直到 License 到期。下次联网时自动续期验证。

【四、采集模式】

  模式一：博主主页（会员功能）
    输入博主主页链接或 sec_uid → 自动抓取该博主全部视频 → 逐条采集评论

    支持的输入格式：
    - https://www.douyin.com/user/MS4wLjAB...
    - MS4wLjAB...
    - 也支持粘贴单个视频链接（免费版可用）

  模式二：指定视频（会员功能）
    每行粘贴一个视频链接，或点击「导入 .TXT 文件」批量导入
    支持的输入格式：
    - https://www.douyin.com/video/123456789
    - 纯数字视频ID（每行一个）

  模式三：搜索结果（会员功能）
    输入搜索关键词 → 自动搜索相关视频 → 采集所有结果的评论

【五、使用流程】

  1. 选择采集模式（免费版仅博主主页模式的单个视频可用）
  2. 输入目标链接/关键词
  3. （可选）展开"高级设置"调整参数：
     - 滚动加载次数：0=自动判断，>0=兜底最大值
     - 最小/最大延迟：控制采集速度，防风控建议 3~8 秒
     - 无头模式：选"是"则浏览器后台静默运行
     - 采集子回复：选"是"同时采集评论下的回复
  4. 点击「开始采集」
     首次使用会弹出浏览器窗口，需要扫码登录抖音
     登录后 cookie 自动保存，下次无需重新登录
  5. 状态栏实时显示进度，可随时点击「停止」
  6. 查看结果：
     - "全部评论" tab：所有采集到的评论
     - "意向客户" tab：仅命中关键词的评论（高亮显示）
  7. 点击「导出 Excel」下载
     超 6 万行自动拆分为多个文件并打包 ZIP

【六、筛选条件】

  在采集时生效（不满足条件的评论不保存）：

  - 地区筛选：如"广东"、"北京"
  - 评论时间筛选：起始日期 至 截止日期
  - 必须包含文字：逗号分隔，满足其一即保留
  - 排除文字：逗号分隔，包含任一即丢弃

【七、关键词管理】

  - 单个添加：输入关键词 → 回车或点"添加"
  - 批量导入：文本框每行一个关键词 → 点"批量导入"
  - 删除：点击标签上的 ×
  - 修改后务必点「保存到文件」

  关键词可手动编辑 keywords.txt 文件（一行一个）。

【八、注意事项】

  1. 防风控建议：
     - 首次使用先小批量测试
     - 延迟建议 3~8 秒，不要太快
     - 不要同时开多个采集任务
     - 大量采集分批次进行

  2. 登录状态：
     - Cookie 保存在 data/cookies.json
     - 过期后重新扫码即可
     - 不要在公共电脑上保存登录状态

  3. 数据存储：
     - 所有数据保存在 data/douyin.db（SQLite）
     - License 缓存：~/.config/dy-scraper2.2/.license_cache
     - 数据不上传任何第三方服务器（仅 License 验证时连接 SCF）

  4. 常见问题：

     Q: 采集不到视频？
     A: 检查博主 ID 是否正确，博主是否为私密账号

     Q: 评论采集不全？
     A: 增大滚动次数，或减小延迟

     Q: 提示浏览器相关错误？
     A: 确认已执行 python -m playwright install chromium

     Q: 抖音提示验证码？
     A: 暂停采集，等待一段时间再试

     Q: 激活失败？
     A: 检查网络连接，确认机器码正确，联系管理员

     Q: 换电脑后需要重新激活？
     A: 是的，机器码绑定硬件

【九、文件结构】

  dy-scraper/
  └── exports/                    # Excel 导出目录

【十、常用命令】

  启动程序：        python app.py
  重装浏览器：      python -m playwright install chromium
  清空采集数据：    点击界面「清空数据」或删除 data/douyin.db
  
客户换电脑：
机器的 Key 是跟着电脑走，在部署的想好，放在那台电脑上使用。
