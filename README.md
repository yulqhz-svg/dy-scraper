# dy-scraper2.2

抖音评论爬取工具。Playwright 负责登录与会话维持，httpx + a_bogus 签名负责数据采集，远程 SCF License 验证实现免费/会员分级。

## 功能特性

- **三种采集模式**：博主主页全量采集、指定视频批量采集、搜索结果采集
- **智能筛选**：按地区、时间范围、包含/排除文字过滤评论
- **意向识别**：自定义关键词库，自动标记意向客户
- **子回复采集**：可选采集评论下的回复链
- **Excel 导出**：单文件（≤6 万行）或自动拆分 ZIP（>6 万行）
- **反检测**：真实浏览器指纹、a_bogus 请求签名、随机延迟、无头模式可选
- **远程授权**：HMAC-SHA256 密码学设备绑定，离线兜底

## 快速开始

### 环境要求

- Windows 10/11 64位
- Python 3.10+
- 能正常访问抖音的网络

### 安装

```bash
pip install -r requirements.txt
python -m playwright install chromium   # 首次约 150MB
```

### 启动

```bash
python app.py
# → http://127.0.0.1:8080
```

### 激活会员

1. 启动后打开浏览器访问 `http://127.0.0.1:8080`
2. 点击右上角「免费版」徽章
3. 复制机器码发给管理员
4. 管理员生成 Key：`python tools/genkey.py <机器码> <天数>`
5. 粘贴 Key 点击激活
